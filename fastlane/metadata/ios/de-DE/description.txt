Ist mein Cluster okay, und wenn nicht, was genau ist kaputt?

Kubernanny beantwortet genau diese Frage für selbst gehostetes Kubernetes. Ein kleiner Agent in deinem Cluster erkennt, was dort läuft (Longhorn, Argo CD, cert-manager, CloudNativePG, Prometheus, Loki, kured und rund 70 weitere), prüft jedes davon so, wie du es von Hand tun würdest, und zeigt pro Cluster eine Ampel. Darunter steht nur, was gerade kaputt ist, warum, und die eine Aktion, die meistens hilft.

Gemacht für den Moment, in dem um 4:10 Uhr das Handy brummt, oder für den Blick vor dem Schlafengehen. Kein weiterer Cluster-Browser, sondern eine klare Antwort.

WAS GEPRÜFT WIRD
• Nodes: NotReady, Druck, RAM und Platte. Geplante kured-Neustarts sind eine Warnung, kein Alarm.
• etcd: Mitglieder, Quorum, WAL-fsync, Leader-Wechsel
• Workloads: CrashLoopBackOff mit den Logs des abgestürzten Laufs, hängende Rollouts, fehlgeschlagene CronJobs
• Volumes: Pending, Lost, fast voll
• Longhorn, cert-manager, Argo CD, CloudNativePG, Prometheus und Alertmanager, Grafana, Loki, Velero, Flux und mehr
• Dazu Nodes, Workloads, Volumes, Ingress-Zertifikate, Events und Verläufe über bis zu sieben Tage

AKTIONEN, ABER SICHER
Genau vier, und nur bei einem offenen Problem: Sync und Hard Refresh einer Argo-CD-App, Neustart eines Workloads, ein CloudNativePG-Backup starten. Der Agent nimmt das Ziel aus seiner eigenen Prüfung, nie aus der App. Löschen kann die App nichts, und auf Wunsch liest der Agent nur.

BENACHRICHTIGUNGEN
Der Agent meldet Probleme selbst über ntfy, Discord, Slack, Gotify oder einen Webhook, sobald sie fünf Minuten bestehen.

PRIVAT VON GRUND AUF
• Ende-zu-Ende verschlüsselt: Jeder Aufruf zwischen App und Agent ist ein Noise-Handshake mit dem Schlüssel deines Geräts. Ingress, Proxy oder WLAN sehen nur Chiffretext. Deshalb reicht auch einfaches HTTP im LAN oder VPN.
• Kein Konto, kein Server von uns, kein Tracking, keine Werbung.
• Der private Schlüssel deines Geräts verlässt es nie. Ein verlorenes Handy sperrst du mit einem Tipp.

SO GEHT ES LOS
1. Den Agent per Helm-Chart oder kubectl apply installieren.
2. Im Log des Agents steht ein QR-Code.
3. Mit der Kamera scannen. Fertig.

Noch kein Cluster zur Hand? Die eingebaute Demo zeigt drei erfundene Cluster, je einen pro Ampelfarbe.

Open Source (Apache-2.0) und kostenlos, ohne Abo und ohne Pro-Version. Quellcode und Anleitung: github.com/kubernanny/kubernanny
